UNDANGAN DIGITAL - TEMA JAWA ELEGAN

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Pastikan index.html, style.css, script.js, dan 1000830842.jpg berada dalam satu folder.
3. Buka index.html di browser.

PENGATURAN DATA
Buka script.js lalu ubah object invitationData di bagian paling atas:
- bride, groom, brideFull, groomFull
- dateText dan dateISO (format YYYY-MM-DDTHH:MM:SS)
- akadTime, resepsiTime, place, mapUrl
- whatsapp (format internasional, contoh 62812...)
- bank, account, accountOwner, giftAddress

NAMA TAMU
Bagikan link dengan parameter, contoh:
index.html?to=Bapak%20Andi

MUSIK
Tambahkan file musik milik Anda dengan nama music.mp3 ke folder yang sama.
Autoplay baru dicoba setelah tombol "Buka Undangan" ditekan.

GALERI
Bagian galeri saat ini menggunakan panel dekoratif. Anda dapat menggantinya dengan foto sendiri pada index.html dan mengatur tampilannya di style.css.

CATATAN
RSVP membuka WhatsApp dengan pesan otomatis. Ganti nomor WhatsApp di script.js.
